# CoinDozer v0.6.3 性能验证记录模板

## 工程变化与限制

- 每帧只构建一次活动资源空间分区；物理子步复用活动索引。最多调度 850 个颗粒；超预算时仍保持每个资源的实体、位置和经济作用，但未被调度的运动体可能短时暂停物理积分。
- 睡眠资源不会存入额外聚合计数，仍保留原对象；相机外资源不提交绘制，但仍存在且参与游戏逻辑。
- 远距简化模型与屏幕渲染分辨率只影响画面；金币、矿石实际转换比和倍数门数据完全不受影响。
- GPU 每帧上传的字节数不等于 GPU 显存占用；不能凭这个值推导内存泄漏。
- 为支持手机性能，低档会减少非核心装饰几何与接触阴影，**不会**删掉真实金币。
- 保留 6500 个最大资源上限，超过容量时依然拒绝部分增殖。

## 游戏逻辑回归

- 验证新旧存档读取，四座双向倍数门 ×2～×20，金币升值支付。
- 推动 100 颗矿石依次进入粉碎机，实测 300 枚金币与事件/统计一致；靠近 6500 上限时不丢失矿石。
- 切换画质不影响金币的数量、碰撞对象标识、玩家位置、行走/转向速度。
- 低画质横竖屏切换时投币区、场景镜头及屏幕坐标反馈位置正确。

本版不提供假造的安卓测量数据。
