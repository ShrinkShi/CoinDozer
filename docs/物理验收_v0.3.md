# v0.3 三维颗粒物理验收

## 视频基准

- 00:14–00:18：蓝球通过宽铲斗挤压堆并向两端流动，视频里有 2–3 层视觉重叠。
- 00:20–00:24：金币不是背包数，受车头压成弧形并溢出。
- 00:26–00:29：通过 X10 后出现更多独立可见球体。
- 00:30–00:37：金币进入升级区域时费用递减，尚不能从广告确定其他计费细节。

## 本轮实现（明确属于近似物理）

1. 每个粒子有位置 `x/y/z`、速度 `vx/vy/vz`。其中 `y` 表示从地面向上的底面高度。
2. 金币采用扁椭球接触体，蓝球近似球形，其他种类按不同半径与高度处理。所有可见粒子受重力、地面反弹及阻尼影响。
3. 通过 XZ 空间哈希查询邻近粒子，在 3D 椭球度量下进行多次非穿透位置投影。使用轻量速度传递，让推力进入邻居而不是直接传送资源。
4. 只有载具向前驾驶且接触到铲斗前缘才推动粒子。接触时加入小幅抬升，铲斗两侧能溢出物体；静止时不吸附。
5. 与 v0.2 的 X10/X10000、金币投入升级、地图切换及存档兼容。指数倍数继续使用权重对象防止浏览器内存失控。

## 尚未实现 / 已知限制

- 只有近似粒子接触：没有严格能量守恒、金币逐枚转动碰撞、连续碰撞检测（高速物体可能穿透）、静态岩石/木桥的刚体接触。
- 铲斗碰撞用前缘与车轮区域的简化边界近似，尚不是和完整七段凹曲面的三角面片求交。
- 多层堆积有基本高度，但未复刻原广告中复杂的金币堆形与球体连续翻滚细节。
- 资源通过 ×10000 依然采取权重聚合显示，而不是为一个物体生成 10000 个渲染实例。
- 没有在真实 Android/iOS 设备上测量持续 FPS、发热或崩溃率，因此无法声称移动端稳定 30 FPS。
