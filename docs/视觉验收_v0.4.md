## 物理和渲染改造

- 使用 `SCOOP_PROFILE` 作为单一结构定义：生成七段钢斗曲面，同时为资源接触计算最近点与曲面法向。
- 只有正向驾驶且触碰铲斗区域时才发生推挤和抬升；不对超出侧面范围的物体施加吸力。
- 金币姿态包含 `tiltX / tiltZ / omegaX / omegaZ / angle`，按移动速度与碰撞传递更新；支持半高度随金币倾斜变化。金币着地后会缓慢回正。
- 金币采用单网格浮雕，蓝球为单球面配合局部坐标纹理；避免大量同物体叠层网格导致手机实例绘制负担上升。
- 围岩使用更圆滑的 80 面低多边形单体，减少原本锯齿尖刺。

## 浏览器验收

执行：

```bash
python build.py
xvfb-run -a python tests/smoke.py
xvfb-run -a python tests/v04_browser.py
```

已通过：390×844 触控布局、1280×720 桌面布局、金币碰撞后前推和上抬、铲斗侧面外无幽灵影响、静止不吸附、金币速度驱动倾斜、倾斜后物理支持高度提高、单金币浮雕几何有效、X10 增殖与逐枚扣费。运行环境：容器中 Chromium + 软件 WebGL；不能据此推断真机帧率。

## 剩余视觉差距与后续优先级

1. **金币堆尚不如原广告高、厚与自然**。可采用更完整的摩擦 / 扭矩约束，或更高阶的 3D 接触体求解。
2. **红色尾罐与铲斗尺寸、钢材质不够贴近 44–50 秒的镜头**。需要针对关键帧做相机投影、3D 车模比例校准。
3. **缺少与熔岩、木桥、岩石、旋转刺轮的连续几何碰撞**。当前场景层与部分玩法逻辑独立。
4. **移动端性能没有真机验收**。需要 Android / iOS 设备采样 P50/P95 渲染时间及内存。
5. **原视频画面包含视频平台 UI**，不是游戏 UI，本项目不应复制平台按钮、播放条、广告商标。

本版本属于与广告接近的可玩原型，而非最终视觉验收通过。
