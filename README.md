# 铲斗矿场 · 广告玩法还原计划

> 当前版本：`0.3 — 颗粒物理 / 铲斗推动 / 堆叠与溢出（仍不是视觉最终稿）`
>
> 依据：用户提供的 58 秒竖屏广告录屏 `1000308091.mp4`。
> **项目未使用原游戏的模型、纹理、音效或源代码。** 原视频包含第三方短视频平台的覆盖层；本项目只模拟其中的游戏内容。

## v0.3 更新：可推挤的三维颗粒

- 新增 `src/granular.js`：按物品厚度区分金币/球体的三维接触模型，包含重力、地面反弹、滚动阻尼、邻域空间分桶和多轮位置约束求解。
- 推铲不再按路径吸附资源：只有在车体向前行驶并实际接触时才推动，拥挤资源可以被顶高并从铲斗边缘溢出。
- X10/X10000 的数量仍按逻辑权重计算，并把复制出的资源作为独立物理粒子；上限为 2800 个视觉对象，防止手机端指数级增长。
- 维持零 npm 依赖、模块开发与静态构建。现有玩家进度使用原有 `localStorage` 键，避免升级后失去存档。
- 回归验证：`python build.py`、`xvfb-run -a python tests/smoke.py` 和 `xvfb-run -a python tests/v03_browser.py`。后一测试覆盖 390、720 竖屏及 1280 横屏、硬碰撞、垂直堆叠、静止无磁吸、侧向溢出。

**限制**：本版属于 2.5D 颗粒接触近似，金币的旋转惯量、铲斗完整曲面接触、资源与石块/木桥碰撞及数千枚资源的高精度堆叠仍未复现。参考视频也无法证实全部数值与刷新规则，不能声称像素级/物理级还原。性能测试在 PC 软件渲染器运行，不能代表真机帧率。

## 立即试玩

- **最方便**：下载 `dist/index.html`，无需网络、无需安装、可直接用现代浏览器打开。部分手机文件管理器的 HTML 预览不支持 WebGL；需要选择 Chrome/Edge/现代手机浏览器。
- **源码模式**：在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000/`；在 GitHub Pages/静态虚拟主机上也能直接托管模块版源码。
- **构建**：`python build.py`。零 npm 依赖，输出 `dist/index.html`（CSS、所有 JS 与 WebGL 着色器均已内联）。

## 操作

在手机上按住游戏任意空白处拖动（浮动摇杆）；在电脑上使用 `WASD` 或箭头方向键。右上角可暂停并打开菜单，在两段视频对应的场景间切换。`P / Esc` 暂停或继续。进度保存在浏览器 `localStorage`。

## 设计边界

- 主游戏区为 **棕色岩地 + 熔岩河 + 木桥 + 蓝球 X10 + 金币堆 + 橙色刺轮 + 数字跑道 + 2500 升级台**；后期场景是 **灰色地面、粉色岩石、金条、X10000 门和蓝色铲斗**。
- **铲斗不会把金币和球体变成背包数字**，场景对象会被推开、发生粒子间的近似碰撞和两侧溢出，保留在地图上。该系统暂不是完整刚体引擎。
- X10 资源可按比例增加真实的可见对象；X10000 则保持正确的**逻辑计数**，为避免手机崩溃，以有限数量、带权重的对象代表更大的资源量。界面明确标注“聚合显示”。
- 视频确认了费用从 `2500` 递减，**但没有透露完整经济规则**。当前 v0.3 仍使用“1 金币扣 1 费用”，并周期性补充金币，供测试。请勿把此作为原游戏已验证机制。
- 视频中的原生游戏 HUD 并不清楚，下方诸多元素来自短视频平台。当前顶部数值条属于试玩辅助 UI，**不是原视频的复制**。
- 游戏音效目前是简单合成提示音；没有使用原广告的音频资源。

## 静态部署

### GitHub Pages

1. 建立空仓库，上传项目所有文件（包括 `dist/`、`.github/`，不要上传原录屏）。
2. 仓库页面打开 `Settings → Pages → Build and deployment → Source`，选 **GitHub Actions**。
3. 将项目推送到 `main`；随附的 `.github/workflows/pages.yml` 自动部署 `dist`。
4. 在 Actions 中确认部署成功，打开 Pages 发布的链接。

### 虚拟主机 / 静态空间

将 `dist/index.html` 放入网站根目录，无需 PHP、数据库、Node 服务器、VPS、API Key 或运行时 CDN。

```text
├─ index.html                  # 模块版页面入口

├─ build.py                    # 生成纯离线单文件发布版
├─ dist/index.html            # 可直接分享的静态发布版
├─ tests/smoke.py             # 浏览器 + 交互 + 数值验证
├─ tests/v03_browser.py       # 三维堆叠、侧溢、性能回归与多分辨率
├─ docs/还原验收清单.md         # 按视频时间码拆解的还原清单
├─ docs/视觉对照_v0.2.md       # 载具与镜头的视觉差异
├─ docs/物理验收_v0.3.md       # v0.3 物理验收与未完成项
└─ .github/workflows/pages.yml
```

## v0.2 改动

- 铲斗：从近似平板改为七段凹曲面，独立立体侧板、铲缘、上缘和液压杆。
- 履带：闭合弧形橡胶履带、独立驱动轮/托轮及鞋块；驾驶员与车体加入更多形状层次。
- 物体：金币厚度、浮雕凸纹及投影；蓝色球体高光。
- 环境：不规则熔岩河、动态熔融纹理、半透明烟雾、不规则巨石和软阴影。
- 相机：固定方位角的柔性跟随和前向预判；电脑滚轮可局部调整画面尺度。
- 保持完全离线静态运行；没有引入外部 CDN、依赖或服务器。

**截至 v0.2 未实现：**真实三维刚体、金币多层真实稳定堆高、逐帧镜头参数校准与原版模型纹理。图像差异见 `docs/视觉对照_v0.2.md`。
